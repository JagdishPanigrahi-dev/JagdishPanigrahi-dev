## 🤖 Aidora — Telegram Group Management Bot

<table width="100%">
<tr>
<td valign="top">

A full-featured Telegram group management bot built on **python-telegram-bot v20+**, running a webhook architecture deployed on **Vercel** with **Turso (async SQLite-compatible)** as the data layer.

**Core capabilities:**
- Multi-level inline menu navigation for features & help
- Anti-raid, admin abuse protection, AFK handler, custom commands
- Advanced promotion system, activity tracker, global points & leaderboard
- Auto-translate, ghost mode, 24-language support
- AI assistant built in — triggered via `/ai` or `@aidora_ai`
- Clone bot support with owner notifications
- Moderation, notes, mini-games (TicTacToe, Dice), force-join, broadcast system
- Custom formatter engine with variable substitution
